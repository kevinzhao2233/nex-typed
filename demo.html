A modern TypeScript typing animation library for the browser.
Terminal-style typing effects with full control over animation, cursor, and callbacks.

Basic Typing & Control

Core animation with start / pause / resume / stop / destroy lifecycle control. Multiple strings are typed sequentially.

strings: ['Hello, World!', 'Welcome to Nex-Typed!', 'Full lifecycle control.']
stopped
🔄
Loop & Delete (Backspace Effect)

Enable loop for infinite cycling. Use deleteStrings to backspace-delete before typing the next string. Manual backspace() and skip() also available.

loop: true · deleteStrings: true · backspaceSpeed: 30
🎯
Cursor Customization

Customize cursor character, blink speed, blink count, hide-on-complete, and inline CSS styles. Use setCursorBlinkSpeed() to change blink speed at runtime.

char: '█' · blink: true · hideWhenComplete: true
char: '▌' · blinkCount: 5 · style: { color: '#fd79a8' }
Runtime blink speed control via setCursorBlinkSpeed()
500ms
🧠
Smart Timing & Speed Profiles

Simulate human typing with humanTypeDelay, add variance with typeSpeedVariance, pause on punctuation with pauseOnPunctuation, and use speed curves like easeIn / easeOut / easeInOut.

humanTypeDelay: { min: 40, max: 150 }
pauseOnPunctuation: true · typeSpeedVariance: 30
speedProfile: 'easeInOut' — starts slow, speeds up, then slows down
🔀
Shuffle & GoTo

Randomize string order with shuffle: true. Jump to any string index with goTo(index). Dynamically change typing speed with setSpeed().

shuffle: true · goTo(n) · setSpeed(n)
60ms
📡
Callback Events

Full lifecycle hooks: onBegin, onStringStart, onStringEnd, onComplete, onPause, onResume, onBackspaceStart, onBackspaceEnd, onLoop, onShuffle.

All callbacks enabled — watch the event log below
🎨
No Cursor & CSS Selector Target

Disable cursor with cursor.enabled: false. Pass a CSS selector string instead of an HTMLElement as the target.

cursor.enabled: false
target: '.css-selector-target' (string selector)

API Reference
Method / Option Type Description
start()() => voidBegin the typing animation
pause()() => voidPause the current animation
resume()() => voidResume from paused state
stop()() => voidStop and reset the animation
destroy()() => voidStop and remove all DOM elements
backspace()() => voidManually trigger backspace deletion
deleteString()() => voidDelete current string then advance
skip()() => voidSkip to end of current string
goTo(index)(n) => voidJump to string at given index
setSpeed(ms)(n) => voidChange typing speed at runtime
getTypeSpeed()() => numberGet current typing speed
setCursorBlinkSpeed(ms)(n) => voidChange cursor blink speed
getCursorBlinkSpeed()() => numberGet current cursor blink speed
